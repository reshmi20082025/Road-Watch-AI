# RoadWatch AI 🚧

## AI-Based Road Damage Detection System

RoadWatch AI is a web application that uses Artificial Intelligence to detect road damage, such as potholes and cracks, from uploaded road images.

## Features
- Upload road images.
- Detect potholes and road cracks.
- Display detected damage with bounding boxes.
- Show prediction confidence.
- Identify road conditions using AI.

## Technologies Used
- Python
- Streamlit
- Roboflow AI
- Pillow (PIL)
- Google Colab

## How It Works
1. Upload a road image.
2. The AI model analyzes the image.
3. The application identifies road damage.
4. Results are displayed with detection boxes and confidence scores.

## Purpose
The project aims to support road condition monitoring and help identify damaged roads more efficiently.

## Future Improvements
- Add GPS-based damage location.
- Create road damage reports.
- Add a map of detected potholes.
- Improve detection accuracy.

## Note
This project is a prototype. AI predictions should be verified before making road maintenance decisions.
